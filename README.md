## 📋 Overview

**Jixu Portfolio** is a sleek, modern, and responsive developer portfolio built with **React + Vite**. It features buttery-smooth animations powered by **Framer Motion**, internationalization support via **i18next**, and a clean dark-mode-first design that showcases projects, skills, and contact information with elegance.

---

## ✨ Features

- 🎨 **Dark-Mode First Design** — Premium aesthetic with glassmorphism effects
- 🌊 **Smooth Animations** — Page transitions and scroll-triggered reveals via Framer Motion
- 🌐 **Multi-Language Support** — Built-in i18n with browser language detection
- 📱 **Fully Responsive** — Pixel-perfect across mobile, tablet, and desktop
- ⚡ **Lightning Fast** — Vite-powered build with optimal code splitting
- 🎯 **SEO Optimized** — Meta tags, semantic HTML, and structured data

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Jixu-Dev/jixu-portfolio.git
cd jixu-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
